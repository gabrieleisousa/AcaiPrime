# REPRODUÇÃO DE INTERFACE A PARTIR DO FIGMA 

## AÇAI PRIME
Projeto de uma tela para uma açaiteira realizado utilizando React Native para a matéria de Programação Para Dispositivos Móveis.

##  Tecnologias e Requisitos

Para rodar e testar este projeto mobile, você precisará de:

- **Framework:** React Native
- **Ambiente de Emulação:** Android Studio (ou dispositivo físico configurado)
- **Gerenciador de Pacotes:** Node.js (npm)

##  Instalação e Execução

Siga os passos abaixo para clonar o repositório e rodar o aplicativo na sua máquina.

### 1. Clonar o repositório
```bash
git clone https://github.com/gabrieleisousa/AcaiPrime.git
cd AcaiPrime
```

### 2. Instalar as dependências
```bash
npm install
```

### 3. Executar o projeto
```bash
npm run start
```
